Crypto · Every.org

Cryptocurrency Donations

Every.org accepts cryptocurrency on behalf of eligible nonprofits, converts the donation to cash, provides the donor receipt, and disburses the realized value to the nonprofit through its charitable giving system.

  • Open KMI’s Every.org donation flow.
  • Select Crypto as the payment method.
  • Choose the supported cryptocurrency you want to donate.
  • Follow Every.org’s secure instructions to complete the gift.
  • Keep the confirmation and tax receipt for your records.

No crypto wallet is stored on KMI’s website.

Every.org handles the cryptocurrency transaction and conversion. KMI’s public GitHub Pages site only stores the public Every.org donation link.

Activation checklist

  1. Claim or create KMI’s nonprofit profile on Every.org.
  2. Create KMI’s Every.org donate link with Crypto enabled.
  3. Paste that public link into window.KMI_DONATIONS.everyOrgDonateUrl.
  4. Create or select the KMI Givebutter campaign.
  5. Add the Givebutter Account ID and Campaign Code for standard online giving.
